**[MCP Packet Tracer](https://github.com/Mats2208/MCP-Packet-Tracer)** · Describe a network in plain language and it gets designed, validated and wired inside Cisco Packet Tracer. 405 stars and 30 forks; network engineers [Simone Spinedi](https://www.youtube.com/watch?v=daJhmwXAKEI) and [Ryan's Routing Table](https://www.youtube.com/watch?v=_dhgNZWzLPA) made videos about it. [Site](https://www.mcpnetwork.top/) · [Case study](https://matsoto.dev/work/mcp-packet-tracer)

**[Dólar Blue Bolivia](https://www.dolarbluebolivia.click)** · Bolivia's parallel exchange-rate tracker, built and run by me. It pulls from 12 sources every minute and serves a public API other sites use. **1.8M monthly page views** on average from September 2025 to August 2026. [Case study and traffic data](https://matsoto.dev/work/dolar-blue-bolivia)
